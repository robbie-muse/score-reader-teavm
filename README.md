# score-reader-teavm

Audiveris 5.11 running on TeaVM 0.16.0 (WasmGC) — a self-hosted,
CheerpJ-free way to run OMR in the browser.

Work in progress. The full WIP stack lives on the `teavm-wip` branch —
see the open pull request from `teavm-wip` for the review, the gaps,
the tradeoffs, and the validation data.
